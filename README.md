# ⚔️ CodeDuel

> **A real-time competitive programming platform to challenge your coding skills.**

Welcome to the **CodeDuel** repository! This is a full-stack web application designed for developers who love competitive programming. It features a clean user interface and a robust backend to handle coding challenges, user submissions, and real-time 1v1 matches. 

---

## ✨ Features

* **Real-Time 1v1 Duels:** Go head-to-head with other coders in real-time.
* **Curated Problem Set:** Tackle algorithmic challenges (from basic arrays to advanced dynamic programming).
* **Automated Code Execution:** Secure and fast evaluation of submitted code.
* **Clean & Modern UI:** A smooth, responsive frontend designed for a distraction-free coding experience.

---

## 🛠️ Tech Stack

**Frontend:**
* React.js / Vite 
* Tailwind CSS
* Deployed on: **Vercel**

**Backend:**
* Java & Spring Boot
* Hibernate / JPA
* RESTful APIs
* WebSockets (STOMP/SockJS)
* Deployed on: **Microsoft Azure**

**Database & DevOps:**
* MySQL
* Docker
* Git & GitHub

## 💻 Local Setup Instructions

### 1. Clone the Repository

git clone [https://github.com/aswinsai12/1vs1-lock.git](https://github.com/aswinsai12/1vs1-lock.git)
cd 1vs1-lock

2. Setup the Backend (Java/Spring Boot)
Open the backend folder in your IDE.

Configure your MySQL database settings in src/main/resources/application.properties.

Run the Spring Boot application. It will start on http://localhost:8080.

3. Setup the Frontend
Open a new terminal and navigate to the frontend folder:

Bash
cd frontend
Install the dependencies:

Bash
npm install
Start the development server:

Bash
npm run dev
Open your browser and go to http://localhost:5173.
